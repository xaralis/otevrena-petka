Místa

Místa z OpenStreetMap za celé město: obchody s potravinami, bankomaty, lékárny, kde se najíst a napít, památky, veřejná WC, pošty, stojany na kola, kontejnery na tříděný odpad, městské sběrné dvory a soukromé výkupny{% if mi_cat.total %}, dnes {{ '{:,}'.format(mi_cat.total).replace(',', ' ') }} míst{% endif %}{% if mi_cat.built_at %}, sestaveno {{ mi_cat.built_at|d }}{% endif %}. Obnovuje se jednou denně. Každé místo má název, co to je, adresu, polohu, otevírací dobu tak, jak ji píše OpenStreetMap, a obvod, ve kterém leží; kontejner a sběrný dvůr i druhy odpadu, stojan počet míst. Soubor stahuje celý aplikace Pardubice do kapsy, takže se nikam neposílá, kde zrovna jste.

REST API

Dokumentace OpenAPI je na /api/docs. Každá sekce má vlastní prefix, usnesení třeba /api/v1/usneseni/.

Obvody. Datové sady, které jsou za celé město, vracejí celé město a každý záznam v nich má pole obvody: id městských obvodů, kterých se týká (mo1–mo8 = Pardubice I–VIII). Parametr ?obvod= vrátí jen záznamy z vybraných obvodů, víc jich oddělte čárkou: ?obvod=mo5, ?obvod=mo4,mo5. Neznámý obvod vrátí chybu 422 se seznamem platných. Zatím ho umí blokové čištění, podněty, uzavírky, odpady a místa.

Jen při změně. Blokové čištění, podněty a místa posílají hlavičku ETag; kdo ji pošle zpátky v If-None-Match, dostane odpověď 304 bez dat, dokud se data nezmění.

curl '{{ base }}/api/v1/usneseni/resolutions?q=parkování&status=usneseni'
curl '{{ base }}/api/v1/usneseni/resolutions/154-2025-z'
curl '{{ base }}/api/v1/usneseni/meetings?body=zmo&year=2025'
curl '{{ base }}/api/v1/uredni-deska/notices?q=rozpočet&active=false'
curl '{{ base }}/api/v1/cisteni?obvod=mo5&ulice=wolkerova'
curl '{{ base }}/api/v1/podnety?stav=1,2&near=50.0254,15.7553&r=300'
curl '{{ base }}/api/v1/podnety?obvod=mo2&stav=1,2,8,9&stari=90'
curl --compressed '{{ base }}/api/v1/mista?obvod=mo5&druh=stojan,kontejner'

AI asistenti (MCP)

Jeden MCP server pro celý portál, bez přihlášení a jen pro čtení. V Claude.ai ho přidáte v Nastavení mezi konektory jako vlastní konektor s adresou:

{{ base }}/mcp

V Claude Code:

claude mcp add --transport http otevrena-petka {{ base }}/mcp

Pro úřad

Formát je popsaný tak, aby ho úřad mohl publikovat rovnou ze svých systémů: specifikace a doporučení. V Česku pro usnesení a hlasování zatím neexistuje otevřená formální norma (OFN).
