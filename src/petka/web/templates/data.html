REST API

Dokumentace OpenAPI je na /api/docs. Každá sekce má vlastní prefix, usnesení třeba /api/v1/usneseni/.

curl '{{ base }}/api/v1/usneseni/resolutions?q=parkování&status=usneseni'
curl '{{ base }}/api/v1/usneseni/resolutions/154-2025-z'
curl '{{ base }}/api/v1/usneseni/meetings?body=zmo&year=2025'
curl '{{ base }}/api/v1/uredni-deska/notices?q=rozpočet&active=false'

AI asistenti (MCP)

Jeden MCP server pro celý portál, bez přihlášení a jen pro čtení. V Claude.ai ho přidáte v Nastavení mezi konektory jako vlastní konektor s adresou:

{{ base }}/mcp

V Claude Code:

claude mcp add --transport http otevrena-petka {{ base }}/mcp

Pro úřad

Formát je popsaný tak, aby ho úřad mohl publikovat rovnou ze svých systémů: specifikace a doporučení. V Česku pro usnesení a hlasování zatím neexistuje otevřená formální norma (OFN).
